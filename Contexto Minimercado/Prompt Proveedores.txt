Aplicación SaaS multi-tenant llamada MiniMercado, construida con ASP.NET Core 6.0 MVC + Razor Views, C#, Entity Framework Core y SQL Server. La arquitectura usa un TenantId como discriminador en todas las entidades, con filtros de consulta globales en el DbContext para aislar datos por comercio. Todas las entidades de negocio implementan la interfaz ITenantEntity que obliga a incluir TenantId.
