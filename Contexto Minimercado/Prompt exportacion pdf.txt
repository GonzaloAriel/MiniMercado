El sistema tiene un diseño fintech inspirado en Ualá, con variables CSS (--bg-card, --text-primary, --border, etc.), soporte de dark mode via clase body.dark-mode, tipografía DM Sans y DM Mono.
Necesito implementar exportación a PDF en todas las tablas y listados del sistema, con las siguientes características:

REQUISITOS GENERALES

La exportación debe funcionar del lado del cliente usando la librería jsPDF + jsPDF-AutoTable, cargadas desde CDN (https://cdnjs.cloudflare.com). No se usa ningún paquete NuGet ni lógica del servidor para generar el PDF.
El PDF generado debe poder descargarse y luego imprimirse desde el navegador. Incluir un botón "Imprimir" que abra el diálogo de impresión del sistema operativo directamente sobre el PDF.
Cada PDF debe tener:

Header con el nombre del comercio (disponible en ViewBag.NombreComercio o User.Identity.Name como fallback), el título del listado, la fecha y hora de generación.
Footer con número de página y texto "MiniMercado - Sistema de Gestión".
Logo si existe en ~/images/Minimercado.png, cargado como base64 antes de generar.
Colores coherentes con el sistema: fondo de encabezado de tabla en #4f46e5 (indigo), texto blanco, filas alternas en #f8fafc, bordes sutiles.


IMPLEMENTACIÓN
Creá un archivo JavaScript centralizado en /wwwroot/js/export-pdf.js con una función reutilizable:
javascriptexportTableToPDF(tableId, titulo, columnas, opciones)
Donde:

tableId: ID del elemento <table> HTML a exportar
titulo: string con el nombre del reporte (ej: "Historial de Ventas")
columnas: array de strings con los encabezados de columnas a incluir (permite excluir columnas de acciones)
opciones: objeto opcional con { orientation: 'landscape' | 'portrait', fileName: 'nombre.pdf' }

La función debe:

Cargar el logo como base64 usando fetch + canvas
Crear el documento PDF con jsPDF
Insertar el header con logo, nombre del comercio, título y fecha
Usar autoTable para renderizar la tabla con estilos
Insertar el footer en cada página
Disparar la descarga automática del archivo


BOTÓN DE EXPORTACIÓN
En cada vista que tenga una tabla o listado, agregar un botón con este estilo consistente con el sistema:
html<button onclick="exportTableToPDF('id-tabla', 'Título', ['Col1','Col2','Col3'])"
        class="btn-export-pdf">
  <svg><!-- ícono de descarga --></svg>
  Exportar PDF
</button>
El botón debe tener estilo propio definido en el archivo CSS global o en cada vista con:

Fondo #4f46e5, color blanco, border-radius 10px, padding 8px 18px, font-weight 600
Hover: fondo #6366f1, leve elevación con box-shadow
Ícono SVG de descarga inline, 16x16px
En dark mode debe mantener el mismo color (no usar variables que se inviertan)

EXCLUSIÓN DE COLUMNAS DE ACCIONES
La última columna de cada tabla que contenga botones de acción (Editar, Ver, Reponer, etc.) no debe exportarse al PDF. La función exportTableToPDF debe aceptar un array de índices de columnas a excluir:
javascriptexportTableToPDF('tabla-ventas', 'Historial de Ventas',
  ['Fecha', 'Producto', 'Total', 'Vendedor'],
  { orientation: 'landscape', excluirColumnas: [4] })
